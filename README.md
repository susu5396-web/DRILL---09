# Drill 9 — 소년 상하좌우 이동

Python 3.10 이상과 Pico2D를 사용합니다.

```powershell
python -m pip install -r requirements.txt
python move_character_with_key.py
```

방향키를 누르면 이동하고 놓으면 정지합니다. ESC 또는 창 닫기로 종료합니다.
좌우 이동 시 시선이 바뀌며 상하 이동과 대기 중에는 마지막 시선을 유지합니다.
대각선 이동도 가능하며 직선과 속도가 같습니다. 반대 방향키를 동시에 누르면
해당 축의 입력이 상쇄되고, 한쪽을 놓으면 남은 방향으로 이동합니다.
창 포커스를 잃으면 입력을 초기화합니다.

화면은 800×600이며 배경을 화면 크기에 맞춰 표시합니다. 100×100 캐릭터
프레임 전체가 화면 안에 머물도록 네 경계를 제한합니다. 벽에 막혀 실제로
움직이지 않으면 대기 애니메이션을 표시하고, 벽을 따라 이동하면 이동 상태입니다.
이동 속도는 초당 200픽셀, 애니메이션은 초당 10프레임입니다.
긴 지연 후 순간 이동을 막기 위해 한 번의 갱신 시간을 0.1초로 제한합니다.

`animation_sheet.png`는 아래부터 좌이동, 우이동, 좌대기, 우대기의 네 행으로
구성되어 있습니다. 각 행의 여덟 프레임을 반복합니다. 이미지는 실행 파일 기준으로
찾으므로 다른 디렉터리에서 절대 경로로 실행할 수 있습니다.

## 검증

```powershell
python -m unittest discover -v
python -m compileall -q character.py controls.py assets.py rendering.py settings.py move_character_with_key.py
```

자동 테스트는 이동, 대각선 속도, 네 경계, 시선 유지, 중복 입력, 프레임 반복,
스프라이트 행, 리소스 경로, 정상 및 오류 종료를 확인합니다.
실제 창에서는 배경과 캐릭터 표시, 좌우 전환 후 상하 이동, 키 해제 후 대기,
네 모서리 접근, 반대 키 동시 입력, 창 전환 후 복귀, ESC 종료를 확인하세요.

`character.py`는 이동과 애니메이션, `controls.py`는 입력 상태,
`rendering.py`는 프레임 출력, `assets.py`는 이미지 로딩을 담당합니다.
기존 마우스 이동 및 달리기 예제는 별도로 실행할 수 있습니다.
